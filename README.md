# Telegram-бот для вивчення слів

## 1. Встав токен

Відкрий `config.py` і встав свій токен від @BotFather замість `PASTE_YOUR_TOKEN_HERE`:

```python
BOT_TOKEN = os.getenv("BOT_TOKEN", "твій_токен_тут")
```

(або задай змінну середовища `BOT_TOKEN` — тоді нічого редагувати не треба)

## 2. Встанови залежності

```bash
pip install -r requirements.txt --break-system-packages
```

(на своєму комп'ютері, поза цим середовищем, просто `pip install -r requirements.txt`)

## 3. Заванта слова в базу даних (один раз)

```bash
python scripts/load_words.py
```

Це створить файл `words_bot.db` і завантажить туди всі 2071 слів з `data/words.csv`.

## 4. Запусти бота

```bash
python bot.py
```

Якщо все ок, побачиш у консолі "Бот запущено...". Тепер можеш писати боту в Telegram: `/start`.

## Як це працює

1. `/start` — учень бачить кнопки з рівнями A1–C1, обирає свій.
2. Одразу після цього бот пропонує обрати годину (з 8:00 до 22:00) для щоденної розсилки.
3. Раз на годину (о :00) бот перевіряє, у кого зараз саме обрана година, і надсилає 3 нових слова цього рівня.
4. Коли слова рівня закінчуються — список автоматично починається заново.
5. `/level` — змінити рівень будь-коли.
6. `/time` — змінити час розсилки.
7. `/progress` — подивитись, скільки слів вже вивчено.

## Важливо: часовий пояс

Бот бере час зі свого сервера (`datetime.now()`). Якщо будеш деплоїти бота на сервер
з іншим часовим поясом, ніж в учнів (наприклад, сервер у UTC, а учні в Києві, UTC+2/+3),
обрана "9:00" прийде не о 9:00 за Києвом. Для простоти зараз усе працює в одному часовому
поясі — тому обирай сервер/хостинг з тим самим поясом, що й твої учні, або дай знати,
і я додам явне зберігання часового поясу в базі.

## Додавання нових слів

Просто редагуй `data/words.csv` (колонки: level, word, translation) і запусти знову
`python scripts/load_words.py` — старі слова не задублюються завдяки унікальному
обмеженню в базі даних.

## Розгортання (щоб бот працював 24/7)

Локально бот працює, поки відкритий термінал. Для постійної роботи розмісти його на:
- VPS (DigitalOcean, Hetzner, Timeweb тощо) — запусти через `systemd` або `screen`/`tmux`
- Хмарні платформи (Railway, Render) — підключи репозиторій і запусти `python bot.py`
